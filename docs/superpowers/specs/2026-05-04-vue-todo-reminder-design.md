# Vue 待办事项提醒工具黑暗主题改版设计

## 目标

在不改变现有待办提醒功能、文案结构和主要交互的前提下，将当前浅色页面整体重构为统一的黑暗系视觉风格，使其更适合夜间使用，并提升界面的层次感、质感和状态辨识度。

## 改版范围

- 保留单页面结构与现有 Vue 逻辑
- 保留待办新增、完成、删除、提醒、本地存储等全部功能
- 保留当前文案框架和信息层级
- 重点调整 `app/src/style.css` 中的全局配色、背景、卡片、表单、按钮、状态样式
- 仅在必要时对 `app/src/App.vue` 做极小幅结构微调，以支撑更好的暗色视觉呈现

## 不做的内容

- 不新增功能
- 不修改提醒轮询逻辑
- 不调整数据模型
- 不引入 UI 框架、动画库或额外依赖
- 不将页面改成完全赛博朋克或高饱和炫光风，避免影响可读性

## 技术约束

- 框架：Vue 3
- 构建工具：Vite
- 语言：JavaScript
- 样式：原生 CSS
- 改动以现有文件为主，不扩大项目复杂度

## 设计方向

本次改版采用“石墨黑基底 + 冷青蓝强调 + 逾期暗红警示”的折中方案。

- 基底使用分层深灰和近黑背景，营造稳定、沉静的夜间氛围
- 重点操作与高亮信息使用冷青蓝发光感强调，增强科技感与可操作性
- 危险与逾期状态继续使用偏红提示，但控制饱和度，避免刺眼
- 面板采用暗色玻璃卡片和细描边，保留层次但不过度浮夸

## 页面结构

页面结构不变，继续保持以下顺序：

1. 顶部 Hero 标题区
2. 数据统计区
3. 通知权限与待办录入区
4. 待办列表区
5. 空状态提示区

## 视觉规范

### 背景

- 页面根背景改为深色多层渐变
- 增加柔和的大面积冷色光斑，避免纯黑背景显得单薄
- 背景对比度要服务内容，不抢正文和表单的阅读焦点

### Hero 区

- 从当前偏卷轴、浅色质感改为深色玻璃感主视觉
- 标题保留强层级，但去掉浅底书卷效果
- 标题、引导文和说明文字改为适配暗色背景的高对比文本
- 保留装饰性，但转为更克制的光影与描边表达

### 面板与卡片

- 所有主面板统一为深色卡片
- 使用半透明深色背景、细边框和柔和阴影提升层次
- 统计卡和待办卡与主面板同体系，但通过边框、背景明暗和状态色做区分

### 表单

- 输入框使用深色底、浅色字、清晰边框
- 聚焦态使用冷青蓝描边或外发光，保证夜间可见性
- 占位文本颜色降低亮度但保持可读

### 按钮

- 主按钮使用青蓝渐变或高亮深色按钮
- 次按钮使用低对比深色底和描边样式
- 删除按钮保持危险色，但在暗色背景下避免过亮

### 待办状态

- 普通待办：中性深色卡片
- 即将到期：带蓝青或琥珀倾向的高亮边框，突出但不报警
- 已逾期：暗红色边框和轻微染色背景
- 已完成：整体降低对比度并保留删除与信息可读性

### 文本层级

- 标题使用高亮浅色文本
- 正文使用偏冷浅灰
- 次级说明与辅助文案使用更低一档的灰蓝色
- 保证所有中文内容在暗底上的对比度足够，不出现“灰上加灰”

## 交互要求

- 所有现有功能必须保持原样可用
- 交互反馈只做视觉层升级，不改变行为
- Hover、focus、active 状态需要适配暗色主题
- 移动端断点布局继续保持现有响应式策略

## 验收标准

- 页面整体视觉明确转为黑暗系，且风格统一
- Hero、统计卡、表单区、列表区不再残留浅色主题主导感
- 表单输入、按钮、badge、待办卡状态在暗色背景下具备良好可读性
- 桌面端与移动端布局都正常显示
- 不引入功能回归，待办新增、完成、删除、提醒逻辑保持正常

## 风险与处理

- 暗色背景下局部对比不足
  - 通过提升文本明度、增加边框和聚焦态发光解决
- 状态色过亮导致页面杂乱
  - 通过压低饱和度和限制发光范围控制
- Hero 区改动过大导致与主体脱节
  - 统一面板材质、边框语言和色彩基调

## 实施策略

1. 先统一全局变量、背景和文字配色
2. 再重做 Hero 区与统计卡视觉
3. 接着调整表单、按钮、提示信息和空状态
4. 最后统一待办卡、状态 badge 与响应式细节
5. 通过本地预览确认页面在桌面端与移动端的观感一致
