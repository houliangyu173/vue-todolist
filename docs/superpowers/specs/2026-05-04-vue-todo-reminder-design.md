# Vue 待办事项提醒工具设计

## 目标

构建一个基于 Vue 的网页版待办事项提醒工具，支持新增、完成、删除待办，设置截止时间，使用浏览器通知提醒，并将数据保存在本地。

## 范围

- 单页面 Web 应用
- 待办字段：标题、截止时间、完成状态、是否已提醒
- 本地数据持久化：`localStorage`
- 提醒方式：浏览器 `Notification API`
- 页面内同时显示逾期和即将到期状态

## 不做的内容

- 用户登录
- 云端同步
- 多端消息推送
- 分类、优先级、日历视图

## 技术方案

- 框架：Vue 3
- 构建工具：Vite
- 语言：JavaScript
- 测试：Vitest
- 样式：原生 CSS

## 页面结构

1. 顶部标题区
2. 通知权限提示区
3. 新建待办表单
4. 待办列表
5. 空状态提示

## 核心交互

### 新增待办

- 用户输入标题和截止时间
- 标题必填
- 截止时间必填
- 保存后加入列表并写入本地存储

### 完成与删除

- 支持切换完成状态
- 支持删除单条待办
- 完成后保留记录，但不再触发提醒

### 提醒机制

- 页面加载后请求通知权限
- 使用轮询检查待办是否到期
- 待办到达截止时间且未完成、未提醒时，触发浏览器通知
- 触发后标记为已提醒，避免重复通知

### 状态展示

- 未完成且未过期：普通样式
- 未完成且已过期：高亮警示
- 已完成：弱化展示

## 数据模型

```js
{
  id: string,
  title: string,
  dueAt: string,
  completed: boolean,
  notified: boolean,
  createdAt: string
}
```

## 验证重点

- 新增待办后页面立即渲染
- 刷新后本地数据仍存在
- 到期任务会被识别为逾期
- 通知逻辑不会对同一任务重复触发

## 风险与处理

- 浏览器可能拒绝通知权限
  - 页面内保留明显提示，不依赖通知作为唯一提醒手段
- 本地时间变化可能影响到期判断
  - 每次检查均按当前系统时间重新计算
