# Vue 待办页书房案头风改版设计

## 目标

在不改动现有待办提醒功能与核心交互的前提下，将当前页面整体视觉从深色科技感改为“书房案头风”的中国风样式，让页面更像一张摊开的旧纸页与案头手札，呈现安静、温润、有书卷气的使用感受。

本次改版不仅调整样式，也同步调整页面标题、分区命名、按钮文案与状态表达，让视觉和语言保持统一。

## 改版范围

- 保留单页面结构与现有 Vue 逻辑
- 保留待办新增、完成、删除、提醒、本地存储等全部功能
- 重点重写 `app/src/style.css` 中的全局视觉语言
- 根据新风格对 `app/src/App.vue` 中的展示文案、局部类名和少量结构做适度调整
- 保持响应式布局可用，移动端不能因为装饰元素而难用

## 不做的内容

- 不新增功能
- 不修改提醒轮询、通知权限或数据结构
- 不引入新依赖、UI 框架或图片资源
- 不做厚重宫廷风、节庆风或大面积高饱和红金风
- 不把文案改得过于生僻，避免影响理解和日常使用

## 设计方向

本次采用“留白书页”路线，关键词如下：

- 旧纸感
- 书页留白
- 木案暖色
- 手札语气
- 朱砂点睛

整体气质参考书房案头摊开的册页，而不是舞台化、景区化的中国风。视觉应当轻、静、柔和，重点在阅读感和书写感。

## 视觉规范

### 整体色彩

- 页面主底色改为米白、浅杏、淡茶色一组暖色系
- 文本主色使用深棕、墨褐，而不是纯黑
- 强调色使用克制的朱砂红，作为印章、重点按钮或状态点睛
- 辅助色可使用极浅的木色、灰褐色，用于边框、纹理和分隔

### 背景与氛围

- 全局背景应模拟旧纸页或书册纸张，不是纯色平涂
- 可以加入极轻的纸张纤维感、浅浅的横向纹理或墨痕式渐层
- 阴影要偏暖，像纸张叠放在木案上形成的轻柔层次
- 装饰密度保持克制，不能让背景喧宾夺主

### Hero 区

- 当前顶部主视觉改造成“扉页 / 题签”式表达
- 标题保持强层级，但更像手札标题或册页页题
- 现有装饰感要从“发光、科技、炫彩”切换为“题签、纸边、印章”
- 主视觉说明文字更像导语或页边批注，语气温和自然

### 面板与卡片

- 主面板、统计卡、表单区、任务卡统一为纸页类材质
- 边框从高对比描边改为更细更柔和的纸边感线条
- 圆角收敛，避免现代 App 式过圆的塑料感
- 卡片之间通过纸页叠放、浅阴影和轻微色差区分层级

### 表单与控件

- 输入框像写在手札上的记录栏，底色偏浅，边框克制
- Focus 态要清晰，但表达方式更像朱笔描边或书签线
- 主按钮可以做成题签 / 朱印风格，但仍需保持现代点击可用性
- 次按钮应更轻，像旁注操作，而不是并列抢主视觉

### 待办状态

- 普通状态保持中性纸页风格
- 即将到期可以用浅赭色、淡朱色或书签色提示，不要做现代霓虹高亮
- 已逾期可以保留更明显的朱砂或暗红提示，但仍要融入纸面体系
- 已完成任务通过降对比、划线和轻度褪色处理表达

### 弹窗提醒

- 提醒弹窗也必须纳入同一视觉体系
- 弹窗像一张被单独抽出的便笺或批注卡，而不是深色模态框
- 按钮和文案语气延续整页风格

## 文案方向

文案从“工具说明语气”调整为“手札式、案头式表达”，但保留清楚易懂。

调整原则：

- 标题更有册页感，例如“待办清卷”“案头小记”“今日札记”这类表达
- 分区名更像栏目题签，而不是产品功能模块名
- 按钮文案更柔和，例如“添一则”“记下此事”“知道了”
- 状态文案可以略带书卷气，但不能让用户猜意思

文案风格应达到“有味道但不费解”的程度。

## 页面结构

页面主结构继续保留：

1. 顶部主视觉区
2. 统计摘要区
3. 通知与录入区
4. 待办列表区
5. 空状态区
6. 到点提醒弹窗

结构不重排，只在必要处做轻量包装，以适配新视觉语言。

## 实现策略

### `app/src/App.vue`

- 调整页面主标题、副标题、分区标题和按钮文案
- 必要时增加少量包裹元素，用于题签、纸边、印章等装饰
- 保留现有数据流、事件和计算属性逻辑

### `app/src/style.css`

- 重写根级色彩、背景和字体栈
- 统一 hero、panel、stat、form、todo-card、badge、modal 的纸页风格
- 优化移动端间距和层次，避免装饰压缩内容区域
- 保持输入、按钮、勾选框和状态信息在浅底上的可读性

## 验收标准

- 页面不再保留当前深色科技风的主导视觉
- 全局形成统一的“书房案头风”而非零散中国风元素拼贴
- 标题、卡片、表单、任务项、提醒弹窗都属于同一套纸页语言
- 文案整体有书卷感，但对首次使用者仍清晰易懂
- 桌面端与移动端都保持良好阅读和操作体验
- 所有原有待办功能保持正常可用

## 风险与处理

- 中国风元素过多导致页面显得堆砌
  - 处理：减少装饰数量，优先依赖配色、留白、题签结构和材质表达

- 文案改得太古导致理解成本上升
  - 处理：保留现代句法，只做轻度风格化

- 浅底色导致状态区分不够明显
  - 处理：通过边框、底色深浅、标签色和字重同时拉开差异

- 装饰性结构影响移动端布局
  - 处理：移动端减少装饰层，优先保留内容可读性和点击面积

## 实施顺序

1. 先统一全局底色、字体、背景和主面板材质
2. 再改 Hero 区与统计卡的书页化表达
3. 接着调整表单、按钮、提示文案与空状态
4. 最后统一任务卡、状态 badge 与提醒弹窗
5. 通过本地预览检查桌面端与移动端观感是否一致
